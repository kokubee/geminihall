設定（使うAIとログイン）

ChatGPT Plus / Pro の利用枠で監査します。API キーは使いません。

ログインで受け取った情報はメモリ上にだけ置き、ディスクには保存しません。そのため、ブラウザを閉じたときや拡張機能を更新したときは、もう一度ログインが必要です。

この方式は OpenAI のアカウント認可を利用しています。OpenAI 側の仕様変更により、使えなくなることがあります。

ChatGPT のプランを使っています

この拡張機能での監査には、あなたの ChatGPT プランの利用枠が使われます。使用状況は ChatGPT の設定で管理できます。

Using ChatGPT plan ・ Manage usage（ChatGPT の設定 → 使用状況）

キーは次のときに消えます。消えたあとは、もう一度入力が必要です。

  • ブラウザ（Chrome）を閉じたとき
  • この拡張機能を更新・再読み込みしたとき
  • 「このAIのキーを消す」を押したとき

キーはパソコンのディスクにも GeminiHall のサーバーにも保存しないため、消えたキーは復元できません。入力する前に、パスワード管理アプリなどにキーを控えておいてください。

監査の利用料は、あなたのアカウントに請求されます。
